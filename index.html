SOBRE EL PROYECTO

¿Cómo funciona Huella Azul?

La página fue desarrollada combinando tres tecnologías fundamentales para la creación de sitios web.

01

HTML

Se utilizó HTML para construir la estructura de la página, los botones, títulos, textos, juegos y diferentes secciones.

02

CSS

CSS permite definir los colores, tamaños, posiciones, diseños, animaciones y la apariencia general de Huella Azul.

03

JavaScript

JavaScript hace posible la interacción. Controla los movimientos de los juegos, los marcadores, las letras y las respuestas de la computadora.

04

Pruebas

Cada juego debe probarse para comprobar que los botones, contadores y diferentes acciones funcionen correctamente.

PROCESO

De una idea a una experiencia interactiva

Primero se definió la estructura de la página. Después se diseñó la interfaz con una identidad visual azul y blanca. Finalmente, se programaron los juegos utilizando JavaScript para convertir la página en una experiencia interactiva.
